# 🌾 AgriTech-AI

**AgriTech-AI** is an AI-powered agricultural assistant built to support smallholder farmers and extension workers across Africa. It combines machine learning, weather forecasting, and a multilingual chatbot to provide personalized and actionable insights for improving farming outcomes.

## 💡 Key Features

- 🧠 **AI Crop Disease Detection** — Diagnose crop diseases through image recognition using Plant.ID technology
- ☁️ **Weather-Based Crop Advice** — Get real-time weather forecasts and agricultural predictions
- 💬 **Intelligent Farming Chatbot** — Ask questions about crops, fertilizers, and farming practices in multiple languages
- 📱 **User-Friendly Interface** — Simple web application designed for ease of use by farmers and extension workers
- 📊 **Agricultural Analytics** — Data-driven insights for crop management and yield optimization

## 🎯 Our Mission

Empowering African farmers with accessible, AI-driven tools to increase yields, reduce crop loss, and improve agricultural decision-making through technology.

## 🏗️ Technology Stack

### Frontend
- **React 19** with TypeScript for modern, responsive user interfaces
- **Tailwind CSS** for clean, mobile-first design
- **Vite** for fast development and optimized builds

### Backend Services
- **Node.js & Express** for chat persistence and user interactions
- **Django REST Framework** for AI model integration and API services
- **SQLite Database** for reliable data storage and management

### AI & Machine Learning
- **Plant.ID API** for advanced crop disease detection and plant identification
- **Cohere AI** for intelligent, context-aware chatbot responses
- **Open-Meteo API** for accurate weather data and agricultural forecasting

## 🌟 Use Cases

### Crop Disease Management
1. **Photo Upload**: Farmers photograph affected crops
2. **AI Analysis**: Plant.ID identifies diseases, pests, or deficiencies
3. **Treatment Recommendations**: Receive specific, actionable advice
4. **Follow-up Support**: Ongoing monitoring and guidance

### Weather-Smart Farming
1. **Location-Based Forecasts**: Get hyper-local weather predictions
2. **Agricultural Alerts**: Receive warnings about adverse conditions
3. **Planting Guidance**: Optimal timing recommendations for crop activities
4. **Risk Management**: Prepare for weather-related challenges

### Interactive Farming Assistant
1. **Natural Language Queries**: Ask questions in English or local languages
2. **Contextual Responses**: Get advice specific to crops, location, and season
3. **Knowledge Sharing**: Access accumulated agricultural wisdom
4. **Continuous Learning**: AI improves responses based on farmer interactions
